How This Module Works

Three steps, all backed by Django's own authentication system — no custom password logic was written for this.

1

Register

Django's UserCreationForm validates the username, checks the password against Django's strength rules, and confirms it matches on both fields.

2

Hash & Store

On form.save(), Django hashes the password with PBKDF2-SHA256 and writes the new row to the built-in auth_user table. Plain text is never stored.

3

Authenticate

On login, authenticate() re-hashes the entered password and compares it to the stored hash. A match starts a session with login().
